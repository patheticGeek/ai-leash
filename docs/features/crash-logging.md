# Crash logging

AI Leash keeps a record when something goes wrong so you can understand what
happened, even if the app closes or needs to be restarted.

## If the app encounters an error

Errors are recorded automatically while you use the app. This includes
problems that cause the app to close, as well as errors that affect part of
the app but do not close the window.

If a problem affects the current screen, AI Leash may show an error message
with an option to reload. Reloading lets you continue working when possible.
The error is still recorded for later review.

## View the crash log

1. Open **Settings**.
2. Select **Crash log**.

The Crash log shows recorded problems from the current and previous app
sessions. If nothing has been recorded, it shows **No crashes logged**.

Use **Refresh** to load the latest entries. Use **Copy** to copy the log so
you can include it in a bug report or share it with someone helping you.
**Clear** removes the recorded entries when you no longer need them.

## Why the crash log is useful

The log gives you details to refer to when reporting a problem, instead of
having to describe an error from memory. When contacting the project
maintainers, copy the crash log and include what you were doing immediately
before the problem occurred. This can make the issue easier to investigate
and resolve.
