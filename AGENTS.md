# AGENTS.md

Context for agents working in this repo. `ai-leash` is a Tauri v2
agentic harness — not an IDE, the editor/file tree/terminal exist to
support the agent chat, not the other way around. It includes a local
Ollama/OpenAI-compatible agent loop and an ACP backend for driving
external agents such as Claude Code and GitHub Copilot CLI.
See `README.md` for the product pitch and `docs/features/*.md` for
per-feature implementation detail — those are kept in sync with the
code and are the first place to check before making backend/frontend
behavior changes.

## Layout

```
src-tauri/src/    Rust backend: chat/, tools/, provider/, acp/, db/,
                  actions.rs, commands.rs, context.rs, pty.rs, state.rs
src/              React frontend (Vite): app/, features/, lib/, store/,
                  ui/, hooks/
docs/features/    Per-feature reference docs — read these, not just
                  the code, when touching a feature they cover
website/          Nextra docs site; content under src/content/ and the
                  favicon/navbar logo are auto-generated by
                  scripts/sync-docs.mjs from README.md, docs/features/,
                  public/logo.svg and src/assets/logo.svg — never edit
                  generated files directly, edit the source and re-sync
public/logo.svg       square app icon (source for `npm run tauri icon`)
src/assets/logo.svg   "ai leash" text wordmark (Settings > About, sidebar)
```

Both logo SVGs share one gradient (`ai-leash-gradient`, orange→purple)
and one leash-motif color (`#a8672b`, curvy strap + loop). Multi-glyph
gradient fills must live in a **single `<path>` element** with a
combined multi-subpath `d` — `gradientUnits="objectBoundingBox"` (the
default) restarts the gradient per-element, so splitting glyphs across
separate `<path>`s makes the gradient repeat instead of sweep once.

## Commands

```bash
npm run tauri dev     # app, hot reload
npm run tauri build   # installer/bundle
npx tsc --noEmit      # frontend typecheck
cd src-tauri && cargo check && cargo test   # backend

# regenerate src-tauri/icons/* from public/logo.svg after editing it
npm run tauri icon -- ./public/logo.svg
```

Verify any SVG/logo change by rasterizing and looking at it, not by
reading the markup — `rsvg-convert public/logo.svg -o /tmp/x.png -w 512`
then `Read` the PNG.

Delete the `src-tauri/icons/{android,ios}` directories as we do not make android/ios apps, and the Tauri icon generator will make them regardless.

## Conventions

- **AGENTS.md/memory/skills are a real product feature here** (see
  `docs/features/context-and-memory.md`) — this file itself is folded
  into the model's system prompt on every turn if you're editing this
  repo from inside the ai-leash app. Directory-scoped `AGENTS.md` files
  under any touched subdirectory are merged in too, shallowest first.
- Docs website content (`website/src/content/**`) and its favicon/navbar
  logo are generated, gitignored, and rebuilt by `sync-docs.mjs` on
  every `predev`/`prebuild` — single source of truth is `README.md` /
  `docs/features/*.md` / the two logo SVGs. Don't hand-edit generated
  output.
- Static export + `basePath: "/ai-leash"` on the docs site
  (`next.config.mjs`): `next/image` in `unoptimized` mode does **not**
  prepend `basePath` to `src` — use a plain `<img>` with the basePath
  hardcoded (matches the existing pattern for `GITHUB_BLOB_BASE` etc.),
  not `next/image`, for local assets there.
- MDX (`@mdx-js/mdx` via Nextra) chokes on a `{` landing as the first
  character of a soft-wrapped continuation line inside a list item —
  even inside an inline code span. `sync-docs.mjs` works around this by
  joining embedded newlines within inline code spans before MDX sees
  them (safe per CommonMark: an embedded code-span line ending already
  renders as a single space); fenced ` ``` ` blocks are left alone.
- Sub-agent conventions and the always-async `spawn_sub_agent` model
  are documented in `docs/features/agent-chat.md` — check there before
  changing anything in `tools.rs`'s sub-agent handling or `chat.rs`'s
  `run_sub_agent`/`resume_after_background_subtask`.
- Don't commit or push unless explicitly asked, even mid-task.
